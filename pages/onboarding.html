QuickSwitcher

v1.5.2

极速、优雅的键盘优先最近标签切换器，配备实时网页缩略图与自适应毛玻璃面板。

⌨️ 操作快捷键

呼出面板 / 步进切换 按住 Alt 保持面板开启，继续点按 Q 切换下一个
Alt + Q
自由方向导航 也可使用 Tab / Shift+Tab 向前向后选择
← → / ↑ ↓
提交并切换标签 松开 Alt 修饰键，或者直接回车
松开 Alt / Enter
关闭标签页 鼠标悬停卡片右上角，左键点击 ❌ 即可直接关闭；或使用键盘 Delete / Backspace
左键 ❌ / Delete
取消并关闭面板 放弃切换，保持停留在当前标签页
Esc
鼠标直接切换 直接点击任意卡片即可跳转至对应标签
鼠标左键

✨ 功能特性

⚡ 实时网页缩略图 智能捕获最近访问页面的即时快照，即使打开数十个标签也能凭借画面瞬间定位。
🎨 自适应毛玻璃设计 无缝适配系统及所在网页的深浅主题，提供 5 款精心调配的强调色与 3 档卡片密度。
🛡️ 特殊页面无缝支持 在 Chrome 内部页、新建标签页或全屏视频等受限场景下，通过迷你弹窗保障一致体验。
喜欢使用 Ctrl+Q 或 Alt+Tab？ Chrome 允许您在原生扩展快捷键页面随时调整或重新绑定该快捷键。
